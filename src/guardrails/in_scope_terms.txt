# Heuristic keyword gate for check_topic_scope in input_guardrails.py.
#
# This is NOT a real topic classifier — it's a keyword-presence check, same
# style as crisis_terms.txt/indecent_terms.txt/prompt_injection_patterns.txt
# elsewhere in this package. If a message contains none of these (and none of
# crisis_terms.txt, which is inherently mental-health-relevant), it's flagged
# "off_topic" and blocked before it reaches the classifier/RAG/LLM.
#
# Tradeoff: a finite keyword list can't cover every legitimate legal or
# mental-health phrasing, so this will have false positives (a real legal
# question worded unusually gets blocked) — that's an intentional choice
# favoring "don't answer clearly off-topic requests" over "never block a
# legitimate one". If false positives turn out to be common in practice,
# widen this list rather than lowering the bar to near-nothing.
#
