Vite dev server · live backend

Legal AI, talking to the real backend

Typed questions hit POST /api/chat, the mic button records with MediaRecorder and transcribes via POST /api/speech-to-text, and uploads go to POST /api/upload — all real calls against the FastAPI backend (proxied by Vite to localhost:8000), the same one api.py's own portal UI and the desktop CLI in src/main.py use. The language buttons below switch both the chat response language and the mic's speech-recognition locale.

First time here?
  1. Pick a language — 🇦🇲/🇬🇧/🇷🇺 below the chat, before you ask anything.
  2. Ask by typing (press t to focus the box) or by voice — click 🎤, speak, click again to stop.
  3. Upload a document or video with 📎 — text files get embedded into the case database, video gets analyzed for actions/emotion.
  4. Watch the status pill top-right — if it says "backend unreachable," start the backend first (see the note at the bottom of this page).
