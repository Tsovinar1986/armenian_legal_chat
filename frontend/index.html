Start the backend with uvicorn api:app --reload --port 8000 from the repo root, then run npm run dev here. Chat depends on Ollama/chromadb; the mic and video transcript need ffmpeg on the backend's PATH and browser microphone permission; video/voice analysis (YOLO/MediaPipe/Whisper) loads at backend startup, so it can take a minute or two after launch before the backend reports itself online.
